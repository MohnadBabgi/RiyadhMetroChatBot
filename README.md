# 🚇 Riyadh Metro FAQ Assistant

 web application that helps users ask questions about Riyadh Metro and receive accurate answers using semantic search with AI embeddings.

## ✨ Features

### User Experience
- 💬 **Chat-style Interface** - Natural conversation experience
- 🌐 **Bilingual Support** - Full Arabic (RTL) and English support
- 📊 **Confidence Scores** - Shows match quality (0-100%)
- 💡 **Smart Suggestions** - Related questions for exploration
- ⚡ **Quick Categories** - One-click access to common topics
- 👍👎 **Feedback System** - User can rate answers

### Smart Search
- 🧠 **Semantic Search** - AI-powered understanding of questions
- 🎯 **Multilingual Embeddings** - Works with Arabic and English queries
- 📝 **Fallback Handling** - Shows multiple candidates for low-confidence queries
- ⚡ **Fast Response** - Sub-second query processing


## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React 18, Tailwind CSS, Framer Motion |
| Backend | Node.js, Express.js |
| Database | SQLite (better-sqlite3) |
| AI/ML | Transformers.js with multilingual embeddings |
| Auth | JWT (jsonwebtoken, bcryptjs) |
| Charts | Recharts |
